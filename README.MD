# Shopping List Parser
RESTFul API that accepts two PDF files that contain similar nutritionist menu in a POST endpoint, it contains text that we need to extract (using OCR) and sum up the portions of each ingredient for our shopping list.

Currently, my wife and me are going to nutritionist and I am creating this little service that help us to save time creating the shopping list.

Why a API service? I would like to come with a better answer but just because I'm a backend dev.
